# Public repository content

Keep this repository and its public development metadata customer-agnostic.

- Do not include customer or tenant identities, brands, domains, assets,
  configuration, infrastructure details, private paths, operational statistics,
  logs, exports, or other customer data.
- Use entirely synthetic fixtures and reserved example domains. Do not merely
  rename production data or copy private application assets.
- Apply the same rule to branch names, commit messages, pull requests, issues,
  screenshots, workflow logs, build artifacts, and package contents.
- Keep deployment- and customer-specific integration work in private locations.
- Before pushing, inspect the diff and publication metadata for these constraints.
